모델이 한 단계 더 발전시키려면 이미지에 있는 특징을 감지해야한다. 
이미지에 있는 원본 픽셀을 보는 것 대신에 이미지를 어떤 구성 요소로 필터링하는 방법이 있다면 어떨까?

1. 원본 픽셀 대신 이런 구성 요소를 매핑하면 이미지 안의 내용을 훨씬 더 효과적으로 감지할 수 있다.
2. 신발을 감지할 때 이미지 아래에서 모여 있는 검은 픽셀에 의해 활성화
3. 하지만 신발이 중앙에 있지 않거나 이미지 프레임을 채우지 못하면 이런 논리가 성립되지 않음

- 특징을 감지하는 방법은 익숙한 사진과 이미지 처리 방법에서 찾을 수 있다. 
- 이미지를 선명하게 만들어 봤으면 수학적 필터를 이미지 픽셀에 적용함
- 필터를 합성곱이라고 하며, 신경망에 이 필터를 사용해 합성곱 신경망을 만들 수 있다.
# 3.1 합성곱

합성곱은 단순히 가중치의 필터로써 픽셀에 가중치 곱해서 새로운 픽셀 값을 만든다.
![[3) 이미지에서 특징 감지하기-1793757911180.webp]]

이미지에 있는 모든 픽셀에 반복해 필터링된 이미지를 만든다.

![[3) 이미지에서 특징 감지하기-1793758132426.webp]]

1) 수직선을 강조하는 합성곱 필터
- 왼쪽 열에 음수, 가운데 열 필터를 0, 오른쪽 열 음수

1) 수평선을 강조하는 합성곱 필터
- 아래 행에 양수, 가운데 행 필터 0, 위 행 음수

이미지의 많은 정보가 축소되기 때문에 이미지를 특성으로 압축하는 필터를 학습할 수 있다는 것을 보여준다. 이런 특성을 레이블에 매핑할 수 있다. 이전에 입력을 출력에 매핑하기 위해 뉴런의 파라미터를 학습시킨다.

# 3.2 풀링

풀링은 이미지 안에 있는 콘텐츠의 의미를 보존하면서 이미지 픽셀을 줄이는 과정이다. 
1. 최대 풀링: 이미지의 픽셀을 추출하면서 가장 큰 값을 선택
2. 평균 풀링: 이미지의 픽셀을 추출하면서 평균 값을 선택
3. 최소 풀링: 이미지의 픽셀을 추출하면서 가장 작은 값을 선택

![[3) 이미지에서 특징 감지하기-1793758887658.webp]]
### Max Pooling vs Average Pooling

풀링의 목적은 최적화 파라미터 개수를 줄이기 위함이다.
목적에 따라 풀링을 두가지 형태로 구현할 수 있다.

1. 최대값 Max를 활용하면 가장 두드러지는 특징을 찾을 수 있다.
> ❝ 그렇다. 최대값이라는 개념을 활용한다면 특징을 잘 찾아낼 수 있다. ❞

2. 반대로 평균 Average은 덜 중요한 요소를 포함할 수 있다.
> ❝ 그럼에도 왜 사용하는 것일까 ? 왜냐하면 분산을 사용할 수 있기 때문이다. ❞

평균과 분산 개념을 활용하여 물체 위치를 보다 쉽게 파악할 수 있기 때문이다.
따라서 우리는 객체 탐지 `Object Detection` 분야에서 `Average Pooling` 을 효과적으로 활용할 수 있다.

### Average Pooling

![[3) 이미지에서 특징 감지하기-1793758697708.webp]]

- `Flatten` 은 다차원 데이터를 `1` 차원 데이터로 변경하는 역할을 한다고 했다.
- 우선 `Global Pooling` 은 `Pooling` 과 달리 사진 한장을 하나의 숫자로 출력할 수 있다.
- 따라서 `Flatten` 의 출력과 `Global Pooling` 출력은 비슷하다.
- 다만 `Max` 또는 `Average` 개념을 포함시킬 수 있으며 출력 길이가 다른 특징이 있다.
- 또한 Global Average Pooling 은 이미지 설명에도 활용되며 `Flatten` 에 비해 성능이 좋다고 알려져있다.

한줄로 정리하면 Global Average Pooling 과 Flatten 은 같은 일을 하며 GAP 를 적용하면 성능 향상을 기대할 수 있다.

# 3.3 합성곱 신경망 만들기

- 합성곱 층으로 tf.keras.layers.Conv2D를 사용
- 이 클래스에서는 층에 사용할 합성곱 필터 개수, 필터 크기, 합성곱 함수 등을 매개변수로 받는다.

```python
# 합성곱 만드는 방식
tf.keras.layers.Conv2D(64, (3, 3), activation='relu', input_shape=(28, 28, 1)),
```
- 이 예제에서는 64개의 합성곱 필터 학습
- 필터는 랜덤하게 초기화, 시간이 지남에 따라 입력을 레이블로 매핑하기 위해 가장 좋은 필터 값으로 학습, 
- (3, 3)은 필터의 크기이며 이게 가장 일반적
- 다른 값으로도 바꿀 수 있고 (5, 5), (7, 7)같은 홀수를 사용
- 입력 크기는 (28, 28)이지마 Conv2D 층은 컬러 이미지를 설계되었기 때문에 세번째 차워능ㄹ 1로 지정
- 따라서 입력 크기는 28 x 28 x 1이 된다.
- 컬러 이미지는 일반적으로 R, G, B 값(빨강, 녹색, 파랑)으로 저장되므로 컬러 이미지의 세 번째 차원은 3이 된다.

```python
# 풀링 만드는 방식
tf.keras.layers.MaxPooling2D((2, 2)),
```
- 풀링 크기는 (2, 2)


```python
import tensorflow as tf

# 1. Fashion-MNIST 데이터셋 불러오기
# 28×28 흑백 의류 이미지, 총 10개 클래스
# 학습 데이터 60,000개, 테스트 데이터 10,000개
data = tf.keras.datasets.fashion_mnist

(training_images, training_labels), (test_images, test_labels) = data.load_data()


# 2. 데이터 전처리
# CNN 입력 형태: (데이터 수, 높이, 너비, 채널)
# 흑백 이미지이므로 채널 수는 1
training_images = training_images.reshape(60000, 28, 28, 1)
test_images = test_images.reshape(10000, 28, 28, 1)

# 픽셀값을 0~255에서 0~1 범위로 정규화
training_images = training_images / 255.0
test_images = test_images / 255.0


# 3. CNN 모델 구성
model = tf.keras.models.Sequential([

    # 입력 이미지: (28, 28, 1)
    tf.keras.Input(shape=(28, 28, 1)),

    # 합성곱층: 3×3 필터 64개로 이미지 특징 추출
    # 출력: (26, 26, 64)
    tf.keras.layers.Conv2D(64, (3, 3), activation='relu'),

    # 최대 풀링: 2×2 영역의 최댓값을 선택하여 크기 축소
    # 출력: (13, 13, 64)
    tf.keras.layers.MaxPooling2D(2, 2),

    # 두 번째 합성곱층: 더 복잡한 특징 추출
    # 출력: (11, 11, 64)
    tf.keras.layers.Conv2D(64, (3, 3), activation='relu'),

    # 두 번째 최대 풀링: 특징 맵의 크기 축소
    # 출력: (5, 5, 64)
    tf.keras.layers.MaxPooling2D(2, 2),

    # 다차원 특징 맵을 1차원 벡터로 변환
    # 5 × 5 × 64 = 1600
    tf.keras.layers.Flatten(),

    # 완전연결층: 뉴런 128개로 특징 학습
    tf.keras.layers.Dense(128, activation='relu'),

    # 출력층: 10개 의류 클래스의 예측 확률 계산
    tf.keras.layers.Dense(10, activation='softmax')
])


# 4. 모델 컴파일
# Adam: 가중치를 업데이트하는 옵티마이저
# Sparse Categorical Crossentropy: 정수 레이블을 사용하는 다중 분류 손실 함수
# Accuracy: 분류 정확도 평가
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)


# 5. 모델 학습
# 전체 학습 데이터를 50번 반복하여 학습
model.fit(training_images, training_labels, epochs=50)
```

### 첫 번째 합성곱 층과 풀링 층
1. 풀링 크기는 2 x 2이므로 이미지 크기는 각 축 방향으로 절반씩 줄어들어 13 x 13이 된다.
2. 합성곱 층은 이를 11 x 11로 줄인다.
3. 풀링에서 오른쪽과 가장자리 픽셀이 버려지고, 이미지는 5 x 5가 된다.
4. 이미지가 두 개의 합성곱 층을 통과하면 결과적으로 많은 5 x 5의 이미지가 만들어진다.

- 각 합성곱은 3 x 3 필터와 절편을 가진다. 밀집 층을 사용했을 때 각 층은 Y = mX + c와 같다. 
- 여기서 m이 파라미터(가중치), c는 절편이다.
- 필터가 3 x 3이기 때문에 9개의 파라미터가 있다는 것을 제외하면 매우 비슷
- 합성곱 필터가 64개이므로 전체 파라미터는 640개이다.
- 파라미터 9개와 절편을 더하면 총 10개가 된다. 여기에 필터 개수 64를 곱한다.

### 첫 번째 MaxPooling 층

- 아무것도 학습하지 않고 이미지 크기를 줄이기만 한다.
- 따라서 학습되는 파라미터가 없으므로 파라미터 개수는 0

### 두 번째 합성곱 층

- 크기가 9인 64개의 필터를 가지며 각 필터는 이전의 64개 필터와 곱해진다.
- 새로운 64개의 필터마다 절편이 있으므로 전체 파라미터 개수는 (64 x (64 x 9)) + 64이다.
- 두 번째 합성곱 층이 학습할 파라미터는 36,928개이다.
- 두 번째 층을 통과하면 이미지 크기는 5 x 5가 되고 64개의 채널 가짐
- 이를 모두 곱하면 1,600개이다.

### Flatten 층

- 이를 펼쳐서 128개의 뉴런을 가진 Dense 층에 주입
- 128개의 뉴런은 각각의 가중치와 절편을 가지므로 Dense 층이 학습할 파라미터 개수는 ((5 x 5 x 64) x 128) + 128 = 204928

### 마지막 Dense 층

- 이전 층의 128개의 뉴런에서 나오는 출력을 받음
- 마지막 파라미터 층 (128 x 10) + 10 = 1,290

### 신경망 훈련법

- 입력 이미지에 레이블에 매핑하기 위해서는 이런 243,78개 파라미터의 최상의 조합을 학습하는 것
- 파라미터가 많아 학습이 오래 걸리긴 하지만 더 좋은 모델을 만든다.
