# 2.2 Fashion-MNIST 데이터셋을 활용한 뉴런의 학습 과정

### 1. 입력 데이터와 뉴런 구성
- Fashion-MNIST는 티셔츠, 바지, 드레스, 운동화 등 10개의 의류 클래스를 분류하는 데이터셋이다.
- 각 이미지는 28×28 크기의 흑백 이미지이며, 총 784개의 픽셀값으로 구성된다.
- 신경망은 여러 개의 뉴런으로 구성되며, 각 뉴런은 입력 데이터에서 특정 패턴을 학습한다.
- 각 뉴런은 가중치(Weight)와 편향(Bias) 이라는 학습 가능한 파라미터를 갖는다.
- 가중치와 편향은 일반적으로 초기값으로 설정되며, 학습 과정에서 지속적으로 조정된다.

### 2. 뉴런의 연산 과정
- 입력된 이미지의 픽셀값은 신경망의 뉴런으로 전달된다.
- 각 뉴런은 입력값에 가중치를 곱한 후 모두 더하고, 편향을 추가한다.
- 계산된 값은 활성화 함수(Activation Function)를 거쳐 다음 층으로 전달된다.
- 여러 뉴런이 서로 다른 특징을 학습하면서 의류를 구별하는 데 필요한 패턴을 추출한다.
- 이러한 연산이 은닉층을 거쳐 출력층까지 반복된다.

### 3. 출력층과 클래스 예측
- Fashion-MNIST는 10개의 클래스를 분류하므로 출력층에 10개의 뉴런을 배치한다.
- 각 출력 뉴런은 하나의 클래스에 대응한다.
    - 뉴런 0 → 티셔츠/상의(T-shirt/top)
    - 뉴런 1 → 바지(Trouser)
    - 뉴런 2 → 스웨터(Pullover)
    - 뉴런 3 → 드레스(Dress)
    - 뉴런 9 → 앵클부츠(Ankle boot)
- 출력층에 Softmax 함수를 적용하면 각 뉴런의 출력값을 클래스별 예측 확률로 변환한다.
- 가장 높은 확률을 가진 클래스를 최종 예측 결과로 선택한다.

### 4. 손실 함수와 옵티마이저를 통한 학습
- 학습 초기에는 뉴런의 가중치가 적절하게 조정되지 않아 예측 정확도가 낮다.
- 10개의 클래스 중 하나를 무작위로 선택한다면 기대 정확도는 약 10%이다.
- 다만 실제 신경망의 초기 정확도가 반드시 10%인 것은 아니다.
- 손실 함수(Loss Function) 는 신경망의 예측값과 실제 정답 사이의 차이를 계산한다.
- 옵티마이저(Optimizer) 는 역전파(Backpropagation)로 계산된 기울기를 이용해 가중치와 편향을 조정한다.
- 이 과정은 미니배치 단위로 반복되며, 전체 학습 데이터를 한 번 사용하는 과정을 1 에폭(Epoch)이라고 한다.
- 학습이 진행되면서 손실이 감소하고, 일반적으로 분류 정확도가 향상된다.
    
### 5. 최종 학습 결과
- 반복 학습을 통해 각 뉴런은 의류 이미지에서 나타나는 다양한 특징과 패턴을 학습한다.
- 여러 뉴런이 학습한 특징을 조합하여 서로 다른 의류 클래스를 구분한다.
- 최종적으로 신경망은 새로운 이미지가 입력되었을 때 티셔츠, 드레스, 운동화 등의 클래스를 예측할 수 있다.

# 2.3. 신경망 설계

```python
import tensorflow as tf
from tensorflow import keras

model = keras.Sequential([
    keras.Input(shape=(28, 28)),                  # 입력층
    keras.layers.Flatten(),                       # 28×28 → 784
    keras.layers.Dense(128, activation='relu'),   # 은닉층: 뉴런 128개
    keras.layers.Dense(10, activation='softmax')  # 출력층: 뉴런 10개
])
```
- Sequential 모델은 여러 층을 가질 수 있다.
- 첫 번째 Flatten은 뉴런의 층이 아니라 입력을 위한 크기를 지정한다.
- Flatten 층은 2D 배열인 행렬을 1D 배열인 벡터로 변환한다.
- Dense는 뉴런의 층, 128개 지정, 이런 층을 은닉층이고 입력과 출력 사이에 위치해 밖에서는 보이지 않으므로 '은닉'되었다고 말한다.
- 뉴런 128개의 파라미터는 랜덤하게 초기화한다.

#### 뉴련의 갯수가 늘어날 경우
- 파라미터가 많아지므로 실행 속도가 느려짐
- 훈련 데이터를 잘 학습하는 신경망이 만들어지지만, 본 적 없는 데이터 처리는 버거워함
- 이를 **과대적합**이라 부른다.
- 반대로 뉴런 개수가 적으면 모델의 학습에 필요한 파라미터가 부족

#### 하이퍼파라미터 튜닝
- 머신러닝에서 하이퍼파라미터는 훈련을 제어하는 데 사용되는 값
- 훈련 또는 학습되는 뉴런의 내부 가중치, 즉 파라미터와는 반대

#### 활성화 함수
- 층의 각 뉴런에 적용되는 함수, 중간 층에 널리 사용되는 함수는 Relu이다.
- Relu 함수는 단순히 0보다 큰 값을 반환하는 함수

#### 출력층
- 또 다른 Dense 층
- 클래스가 10개이므로 10개의 뉴런을 둡니다.
- 각 뉴런은 입력 픽셀이 해당 클레스에 속할 확률을 출력
- 따라서 가장 높은 값을 찾아야 함
- 이 값을 찾기 위해 루프를 반복할 수 있지만 softmax 활성화 함수가 이를 대신함

### 2.3.1 전체 코드

```python
import tensorflow as tf

data = tf.keras.datasets.mnist

(training_images, training_labels), (test_images, test_labels) = data.load_data()

training_images = training_images / 255.0
test_images = test_images / 255.0
  
model = tf.keras.models.Sequential([
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(128, activation=tf.nn.relu),
    tf.keras.layers.Dense(10, activation=tf.nn.softmax)
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(training_images, training_labels, epochs=5)
```

```python
data = tf.keras.datasets.mnist
```
- 케라스는 한 줄의 코드로 로드할 수 있는 데이터셋 내장
- 이 경우 7만 개의 이미지를 다운로드해 훈련 세트와 테스트 세트로 나누는 작업 등을 수행 필요 없음

```python
(training_images, training_labels), (test_images, test_labels) = data.load_data()
```
- load_data() 메서드로 호출하면 훈련 세트와 테스트 세트가 반환
- 6만 개의 훈련 이미지와 1만 개의 테스트 이미지로 구성
- training_images는 6만 개의 28 x 28 픽셀 배열이고 training_labels는 6만 개의 원소(0~9)로 이루어진 배열
- test_images는 1만 개의 28 x 28 픽셀 배열이고 test_labels는 0에서 9 사이의 1만 개의 값을 담은 배열
- 신경망이 훈련하는 동안 볼 수 없도록 테스트 이미지와 테스트 레이블은 따로 보관

```python
training_images = training_images / 255.0
test_images = test_images / 255.0
```
- 이미지 픽셀이 모두 흑백이므로 0~255 사이값을 가진다.
- 255로 나누면 각 픽셀을 0~1 사이의 값으로 나타낼 수 있다.
- 이런 과정을 **정규화**라고 한다.
- 텐서플로에선 신경망을 훈련할 때 정규화가 성능을 높인다.
- 정규화되지 않은 데이터를 다루면 종종 신경망이 학습하지 못하거나 오류가 발생하기 쉽다.

```python
model = tf.keras.models.Sequential([
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(128, activation=tf.nn.relu),
    tf.keras.layers.Dense(10, activation=tf.nn.softmax)
])
```
- 신경망 정의 코드

```python
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```
- 모델 컴파일할 때 손실 함수와 옵티마이저를 지정
- 손실 함수는 **희소한 범주형 크로스 엔트로피(Sparse Categorical Cross Entropy)**라고 부른다.
- 이 손실 함수는 하나의 숫자를 예측하는 것이 아니라 하나의 카테고리를 선택
- 의류 아이템은 10개의 카테고리 중 하나에 속해 있기 때문에 범주형 손실 함수를 사용
- 옵티마이저는 adam을 선택, 앞서 선택한 sgd보다 더 진화한 것
- 훈련 속도를 높이는 것이 도움이 되므로 adam 옵티마이저 선택
- 정확도는 입력 픽셀을 출력 레이블에 얼마나 정확하게 매핑하는지 알려줌

```python
model.fit(training_images, training_labels, epochs=5)
```

# 2.7 훈련 조기 종료

- 지금까진 훈련할 에폭을 하드코딩, 그러나 원하는 성능이 나올 때까지 에폭 수를 바꾸고 훈련하는 대신에, 원하는 정확도에 도달하면 훈련을 멈추게 하는 것이 좋다.
- 모델이 훈련 세트에서 정확도 90%의 정확도에 도달할 때 까지 훈련하고 싶다면 어떻게 해야하나?

```python
import tensorflow as tf

class myCallback(tf.keras.callbacks.Callback):
    def on_epoch_end(self, epoch, logs={}):
        if(logs.get('accuracy')>0.90):
            print("\n정확도가 90%를 넘었으므로 학습을 중단합니다.")
            self.model.stop_training = True

callbacks = myCallback()
mnist = tf.keras.datasets.fashion_mnist

(training_images, training_labels), (test_images, test_labels) = mnist.load_data()
training_images = training_images / 255.0
test_images = test_images / 255.0

model = tf.keras.models.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),
    tf.keras.layers.Dense(128, activation=tf.nn.relu),
    tf.keras.layers.Dense(10, activation=tf.nn.softmax)
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(training_images, training_labels, epochs=15, callbacks=[callbacks])
```

- Callback 클래스 생성, 이 클래스는 tf.keras.callbacks.Callback 상속
- myCallback 클래스 안에 on_epoch_end 함수를 정의
- 이 함수로 에폭에 대한 자세한 로그가 제공
- 이 로그에는 정확도가 포함되어 있기 때문에 이 값이 0.90보다 큰지 확인 가능
- 정확도가 0.90보다 크면 self.model.stop.training = True를 통해 멈춤
- myCallback 클래스를 정의한 후 이 클래스의 인스턴스 callbacks 객체를 만든다.
- 훈련할 때 에폭 끝에서 콜백 함수가 호출
- 에폭이 종료될 때마다 정확도 확인 후 90% 이상 달성하면 종료
