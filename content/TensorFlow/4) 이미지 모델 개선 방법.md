# 4.1 이미지 증식

이미지 증식은 텐서플로가 데이터를 로드할 때 이미지에 여러 변환을 적용해 새로운 데이터를 추가로 만드는 기법

![[4) 이미지 모델 개선 방법-1793930400023.webp]]

- 회전, 수평 이동, 수직 이동, 기울임, 확대, 반전
- 이미지 증식 전에 이미지 정규화는 선행적으로 진행할 것

```python
train_datagen = ImageDataGenerator(rescale=1/255) # 이미지 정규화
```

텐서플로 ImageDataGenerator를 통한 이미지 증식

```python
# 훈련 데이터 이미지 증식
from tensorflow.keras.preprocessing.image import ImageDataGenerator

# 훈련 데이터 이미지 증식 설정
train_datagen = ImageDataGenerator(
    rescale=1./255,
    rotation_range=40,          # 이미지를 무작위로 회전 (0~40도)
    width_shift_range=0.2,      # 이미지를 수평으로 무작위 이동 (전체 너비의 20%)
    height_shift_range=0.2,     # 이미지를 수직으로 무작위 이동 (전체 높이의 20%)
    shear_range=0.2,            # 이미지를 무작위로 전단 변환
    zoom_range=0.2,             # 이미지를 무작위로 확대/축소
    horizontal_flip=True,       # 이미지를 무작위로 수평 뒤집기
    fill_mode='nearest'         # 이미지를 이동/회전/확대할 때 생기는 공간을 채우는 방식
)

```

- 매개변수로 훈련 제너레이터를 다시 만들어 훈련하면 이미지 처리 때문에 훈련 시간이 더 오래 걸리는 것을 알 수 있다.
- 모델 정확도가 이전만큼 높지 않을 수 있다.
- 하지만 검증 정확도는 높여질 수 있다.

```python
# 모델 생성, 컴파일 생략
# 확실히 학습 훈련 시간이 많이 늦어짐
model.fit(train_generator, epochs=15)
```

- 검증 정확도가 훈련 정확도보다 높거나 비슷하면 과소적합이 되었다는 것이므로 매개변수를 조정하는 것이 좋음
- 검증 및 테스트 코드는 생략, 이전 코드와 같음

# 4.2 전이 학습

- 모델의 성능을 높일 수 있는 또 다른 방법은 다른 곳에서 이미 학습한 특성을 이용하는 것이다. 
- 많은 연구자들이 수천 개의 클래스를 가진 대용량 데이터셋 대규모 모델 제공
- 전이 학습이란 개념을 사용하면 모델이 학습한 특성을 개인화 된 데이터에 적용

### 전이학습의 개념

- 데이터셋의 밑바닥에서부터 합성곱 필터를 사용하는 것보단 더 많은 특성을 가진 대규모 데이터셋에서 학습된 필터를 사용하는 원리
- 미리 학습된 필터를 사용해 훈련 데이터로 모델을 최적화
- 수 천개의 클래스로 훈련된 기존 모델을 사용할 수 있지만, 기존 신경망 일부를 버리고 두 개의 클래스를 분류하는 층을 추가 가능

![[4) 이미지 모델 개선 방법-1793931739136.webp]]

- 모델이 훈련되고 나면 모델 구조(층의 필터 개수, 필터 크기 등)와 함께 모든 층은 필터 값, 가중치, 절편을 나타내는 일련의 숫자에 불과
- 하지만 재사용하는 아이디어는 간단함
- 이 코드에선 Incepion v3 모델을 사용, 이 데이터셋은 ImageNet DB에 제공하는 수백만 개 이상의 이미지에서 훈련됨
- 수십 개의 층이 존재하고 이미지를 천 개의 클래스로 분류할 수 있음
- 사전에 훈련된 가중치를 담은 모델을 사용 가능

#### 전이학습 모델 코드

```python
# 1. 전이학습(Transfer Learning)
# 사전 학습된 모델의 특징 추출 능력을 새로운 데이터셋에 활용하는 방법
from tensorflow.keras import layers, models
from tensorflow.keras.applications.inception_v3 import InceptionV3
import urllib.request

# 2. InceptionV3 사전 학습 가중치 다운로드 URL
# ImageNet 데이터셋으로 학습된 가중치 사용
# notop: 기존 모델의 최종 분류층이 제외된 가중치
weights_path = 'https://storage.googleapis.com/tensorflow/keras-applications/inception_v3/inception_v3_weights_tf_dim_ordering_tf_kernels_notop.h5'

# 3. 다운로드할 가중치 파일 이름
weights_file = "inception_v3.h5"

# 4. 사전 학습된 가중치 다운로드
# URL에서 가중치 파일(.h5)을 로컬에 저장
urllib.request.urlretrieve(weights_path, weights_file)

# 5. 사전 학습된 InceptionV3 모델 불러오기
pre_trained_model = InceptionV3(
    weights=weights_file,      # 다운로드한 사전 학습 가중치 적용
    include_top=False,        # ImageNet의 기존 분류층 제거
    input_shape=(300, 300, 3) # 입력 이미지 크기: 300×300 RGB
)

# 6. 모델 구조 확인
# 각 층의 출력 형태와 파라미터 개수 출력
pre_trained_model.summary()
```

- mixed7 층의 출력이 7 x 7크기로 작기 때문이 이를 사용함
- 물론 다른 층으로 모델 실험을 해봐도 좋음
- 다시 훈련하지 않기 위해 전체 신경망 동결 후 mixed7 출력을 가리키는 변수를 지정 후 이 지점에서 신경망을 자름

#### 가중치 동결 
```python
# 1. 사전 학습된 모델의 가중치 동결 (Freezing)
# InceptionV3의 모든 층을 학습하지 않도록 설정
# 기존 ImageNet에서 학습한 가중치를 유지하고 특징 추출기로 활용
for layer in pre_trained_model.layers:
    layer.trainable = False


# 2. InceptionV3의 특정 층 선택
# mixed7: InceptionV3의 중간 특징 추출층
# 기존 최종 출력 대신 mixed7의 특징 맵을 사용
last_layer = pre_trained_model.get_layer('mixed7')


# 3. 선택한 층의 출력 형태 확인
# 출력 Shape: (None, 높이, 너비, 채널 수)
# None: 배치 크기가 고정되지 않았음을 의미
# 채널 수: 768개
print('last layer output shape:', last_layer.output.shape)


# 4. 선택한 층의 출력 텐서 가져오기
# mixed7에서 추출한 특징 맵을 새로운 분류층에 연결하기 위해 사용
# 실제 이미지 예측값이 아니라 모델을 구성하는 심볼릭 텐서
last_output = last_layer.output
```

```text
last layer output shape:  (None, 17, 17, 768)
```

1. 마지막 층의 출력 크기를 출력하면 결과가 7 x 7임을 알 수 있음
2. 출력 크기는 채널 차원을 포함한 7 x 7 x 768
3. 이 결과는 이미지를 주입하면 mixed 층에서 7 x 7 크기의 특성 맵을 출력

#### mixed7을 선택하는 이유

- 특징 재사용: ImageNet에서 학습한 시각적 특징을 활용한다.
- 중간 특징 활용: 기존 최종 출력보다 앞선 mixed7 층의 특징을 사용한다.
- 새로운 분류층 연결: 추출한 특징 맵을 기반으로 말과 사람을 구별하는 분류층을 추가할 수 있다.
- 학습 비용 감소: 기존 가중치를 동결하여 새롭게 추가한 분류층의 파라미터만 학습할 수 있다.
#### 밀집 층 추가

```python
# 출력을 펼쳐서 1차원으로 만듬
x = layers.Flatten()(last_output)

# 1.204개의 은닉 유닛과 ReLU 활성화 함수를 가진 완전 연결층 추가
x = layers.Dense(1024, activation='relu')(x)

# 분류를 위해 시그모이드 함수 사용 최종 층 추가
x = layers.Dense(1, activation='sigmoid')(x)
```

- 마지막 층의 출력을 밀집 층에 주입하기 위해 펼침,  그 다음 1024개의 뉴런을 가진 밀집 층과 출력을 위해 1개의 뉴런을 가진 밀집 층을 추가
- 사전 훈련된 모델의 입력과 x를 사용해 모델 정의가 가능해짐
- 이렇게 케라스 Model 클래스를 사용해 신경망을 만드는 방법을 함수형 API
- 층 객체에 입력을 전달해 반환 받는 출력을 다시 다른 층의 입력으로 전달하는 식으로 층을 연결
- 그 다음 Model 클래스에 처음 입력과 최종 입력을 전달해 모델을 만듬

```python

from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import RMSprop

# 1. 전이학습 모델 생성
# Model(): 입력층과 출력층을 지정하여 모델 구성
# pre_trained_model.input: InceptionV3의 입력층
# x: 사전 학습 모델에 새롭게 연결한 최종 출력층
# x는 앞선 코드에서 정의되어 있어야 한다.
model = Model(
    inputs=pre_trained_model.input,
    outputs=x
)


# 2. 모델 컴파일
# optimizer: 가중치를 업데이트하는 최적화 알고리즘
# loss: 예측값과 실제 정답의 차이를 계산하는 손실 함수
# metrics: 학습 성능을 평가하는 지표
model.compile(

    # RMSprop: 기울기 제곱의 이동평균을 활용하는 옵티마이저
    # learning_rate=0.0001: 가중치 업데이트 크기를 조절하는 학습률
    optimizer=RMSprop(learning_rate=0.0001),

    # Binary Crossentropy: 말과 사람을 구분하는 이진 분류 손실 함수
    loss='binary_crossentropy',

    # Accuracy: 전체 데이터 중 정답을 맞힌 비율
    metrics=['accuracy']
)
```

# 4.3 다중 분류

- 다중 분류는 출력 층에 시그모이드 활성화 함수를 사용하는 하나의 뉴런을 이용하는 것이 아니라, 분류하려는 클래스 개수에 해당하는 n개의 뉴런을 사용
- 여러 개의 클래스에 적합한 손실 함수로 바꿔야 함
- 이진 분류기의 손실 함수는 이진 크로스 엔트로피
- 다중 분류기의 손실 함수는 범주형 크로스 엔트로피
- 텐서플로는 ImageDataGenenrator를 사용해 데이터를 읽으면 레이블이 자동으로 부여
- 캐글에서 Rock Paper Scissors Dataset 다운로드 진행

```python
"""
데이터셋에서 제너레이터를 만들 때 두 개 이상의 하위 디렉터리에서 ImageGenerator를 사용해야 하므로 class_mode 매개변수를 categorical로 지정
"""

train_generator = training_datagen.flow_from_directory(
    'Rock-Paper-Scissors/rps', # 학습 데이터 경로
    target_size=(150, 150), # 이미지 크기 조정
    batch_size=32, # 배치 크기
    class_mode='categorical' # 다중 클래스 분류
)
```

모델 신경망 정의

```python

import tensorflow as tf

# 1. CNN 모델 구성
# 입력 이미지: 150×150 크기의 RGB 이미지
# 가위, 바위, 보를 구분하는 다중 클래스 분류 모델

model = tf.keras.models.Sequential([

    # 입력층: 이미지 크기 (150, 150, 3)
    tf.keras.Input(shape=(150, 150, 3)),

    # 첫 번째 합성곱층: 3×3 필터 16개로 기본 특징 추출
    # 출력: (148, 148, 16)
    tf.keras.layers.Conv2D(16, (3, 3), activation='relu'),

    # 최대 풀링: 특징 맵 크기 축소
    # 출력: (74, 74, 16)
    tf.keras.layers.MaxPooling2D(2, 2),

    # 두 번째 합성곱층: 3×3 필터 32개로 추가 특징 추출
    # 출력: (72, 72, 32)
    tf.keras.layers.Conv2D(32, (3, 3), activation='relu'),

    # 최대 풀링: 특징 맵 크기 축소
    # 출력: (36, 36, 32)
    tf.keras.layers.MaxPooling2D(2, 2),

    # 세 번째 합성곱층: 3×3 필터 64개로 복잡한 특징 추출
    # 출력: (34, 34, 64)
    tf.keras.layers.Conv2D(64, (3, 3), activation='relu'),

    # 최대 풀링: 특징 맵 크기 축소
    # 출력: (17, 17, 64)
    tf.keras.layers.MaxPooling2D(2, 2),

    # 다차원 특징 맵을 1차원 벡터로 변환
    # 17 × 17 × 64 = 18,496
    tf.keras.layers.Flatten(),

    # 완전연결층: 뉴런 128개로 추출된 특징 학습
    tf.keras.layers.Dense(128, activation='relu'),

    # Dropout: 학습 시 뉴런 출력의 50%를 무작위로 비활성화
    # 과적합(Overfitting) 완화
    tf.keras.layers.Dropout(0.5),

    # 출력층: 3개 클래스의 예측 확률 계산
    # Softmax: 각 클래스의 확률 합이 1이 되도록 변환
    tf.keras.layers.Dense(3, activation='softmax')
])

# 모델 구조 확인
model.summary()
```

# 4.4 드롭아웃 규제

- 과대적합은 신경망이 특정한 종류의 입력 데이터에 과도하게 맞춰져 다른 데이터에서는 성능이 나쁜 경우가 있다. 
- 이를 극복하기 위한 기법은 드롭아웃 규제이다.
- 신경망을 훈련 시 개별 뉴런은 같은 층의 다른 뉴런에 영향 받음
- 특히 신경망 규모가 크다면 시간이 지남에 따라 일부 뉴런이 과도가헥 전문화
- 이후 층에도 이런 영향이 전달되어 전체적으로 신경망이 전문화되어 과대적합초래
- 또한 이웃한 뉴런이 비슷한 가중치와 절편을 가질 수 있음
- 이를 모니터링 하지 않으면 전체 모델이 이런 뉴런에 감지한 특성에 특히 민감함

```python

tf.keras.layers.Dropout(0.5),
```

- 앞선 모델 정의 신경망에선 드롭아웃 규제를 진행했었음
- 이 코드는 이전 층의 있는 뉴런 중에서 지정된 양(여기선 50%)만큼 랜덤하게 드롭아웃 시킴
- 전이 학습에서 모델의 층을 다른 층으로 수정할 수 있듯이, 드롭아웃 규제도 마찬가지로 여러가지 실험을 통해서 최적의 퍼센트를 찾아야 함
