# 1.1 머신러닝

- 먼저 머신러닝이 전통적인 프로그래밍에서 어떻게 발전했는지 생각
- 전통적 프로그래밍은 프로그래밍 언어로 표현된 규칙을 작성하고 데이터에 이 규칙을 적용해 정답을 제공
- 규칙은 프로그래밍 언어로 표현, 이런 규칙은 데이터에 적용되고 결과를 반환함

# 1.2 프로그래밍에서 학습으로

- 규칙을 만드는 대신에 데이터와 정답을 제공하고 규칙이 무엇인지 찾아내는 방법이 있다면?
- 머신러닝에선 이를 정의하는 개념도를 생각함

![[1) 텐서플로 소개-1793664841309.webp]]

- 규칙을 직접 찾지 않음
- 대신 상황에 맞는 데이터를 준비하고 이 데이터에 레이블을 부여함
- 컴퓨터가 어떤 데이터는 이 레이블에 일치하고 다른 데이터는 저 레이블에 일치하도록 하는 규칙을 찾음
- 머신러닝에선 이를 정의하는 개념도를 생각함
# 1.3. 텐서플로란?

- 텐서플로는 머신러닝 모델을 만들고 사용하기 위한 오픈소스 플랫폼
- 머신러닝에 필요한 많은 알고리즘과 패턴을 텐서플로에 구현
- 이면에 있는 수학이나 로직을 모두 배울 필요는 없음
- 웹, 클라우드, 모바일, 임베디드 시스템으로 모델을 배포하는 것까지 지원

![[1) 텐서플로 소개-1793665092612.webp]]

- 머신러닝 모델을 만드는 과정을 **훈련**이라고 부른다.
- 컴퓨터가 일련의 알고리즘을 사용해 입력에 대해 학습하고 입력 사이의 차별점을 구별
- 예) 고양이 / 강아지 구별하도록 훈련 -> 고양이와 강아지 이미지 여러 개 사용해 모델 만듬
- 컴퓨터는 이 모델을 이용해 고양이와 강아지를 구별하는 특징을 찾음
- 모델이 훈련 되고 나면 이를 사용해 새로운 입력을 인식 및 분류하는데, 그 과정을 **추론**이라고 부른다.

### 모델 훈련을 위한 필요사항

모델 자체를 설계하기 위한 API

1. 모든 것을 직접 코딩
2. 컴퓨터가 학습하는 로직을 파악해 코드로 구현(권장하지 않음)
3. 텐서플로에 내장된 추정기(estimator)를 사용

추정기는 사전에 구현된 신경망(Neural Network)이며 이를 커스텀마이징도 가능, 또한 Keras를 사용해 일반적인 머신러닝 개념 코드로 캡슐화 가능

### 모델 훈련 방법

- 대부분의 경우 하나의 칩을 사용, CPU, GPU, TPU라고 불리는 새로운 칩
- 고급 개발이나 연구 환경에선 여러 칩으로 병렬 훈련을 진행
- 여러 칩으로 훈련 확장을 위해선 분산 전략 사용

### 텐서플로의 특징

모든 모델의 핵심은 데이터, 텐서플로는 모델 학습 과정을 쉽게 처리하기 위해서 텐서플로 데이터 서비스라는 API 제공, 훈련을 위해 한 줄의 코드로 사용할 수 있는 전처리된 데이터셋을 제공하며, 원시 데이터를 쉽게 사용하도록 처리하는 도구도 제공

많은 사람들이 사용할 수 있도록, 텐서플로는 클라우드나 웹에서 HTTP 연결을 토해 모델 추론을 제공할 수 있는 서빙 API를 제공

- 모바일이나 임베디드 시스템에서 모델 추론할 경우 텐서플로 라이트(Tensorflow Lite)도 제공
- 텐서플로 라이트 마이크로(TFLM)을 사용하면 마이크로컨트롤러에서 추론을 수행할 수 있음
- 이 분야를 TinyML이라고 부름
- 또한 브라우저나 Node.js로 모델을 서비스하고 싶으면 TensorFlow.js를 사용해 모델 훈련 가능

# 1.4 머신러닝 시작하기

텐서플로를 코드를 작성해 패턴을 찾은 신경망을 만든다.

```python
# 신경망 라이브러리 호출
import tensorflow as tf
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense
```

```python
# 간단한 신경망,하나의 층과 하나의 뉴런을 가짐
model = Sequential([Dense(units=1, input_shape=(1,))])
model.compile(optimizer='sgd', loss='mean_squared_error')

xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)

model.fit(xs, ys, epochs=500)
print(model.predict([10.0]))
```

### 신경망

![[1) 텐서플로 소개-1793666700650.webp]]

```python 
model = Sequential([Dense(units=1, input_shape=(1,))])
```
- 신경망 그림에서 각각의 동그라미는 뉴런이고 세로 한 줄로 나열된 동그라미는 Layer이다.
- 텐서플로를 사용할 떄는 Sequential 클래스로 층을 정의
- Sequential 클래스 안에서 층의 형태를 지정
- Sequential 클래스 안에 한 줄의 코드만 있으므로 하나의 층만을 가짐
- keras.layes API를 사용해 층을 정의함
- Dense는 뉴런이 완전히(조밀하게) 연결되어 있다는 것을 의미
- Dense 층을 units=1로 설정했기 때문에 이 층은 1개의 뉴런을 가짐
- 전체 신경망에 이런 밀집 층을 한 개 사용한다.
- 마지막으로 신경망에 등장하는 첫 번째 층을 정의할 때 입력 데이터 크리를 지정

```python 
model.compile(optimizer='sgd', loss='mean_squared_error')
```
- 손실 함수 정의, 손실 함수는 모델의 추측이 얼마나 좋고 나쁜지 측정
- X가 -1, 0, 1, 2, 3, 4일 때 정답을 알고 있으므로 손실 함수는 추측으로 만든 답과 비교
- Y = 10X + 10으로 추측했다면, X가 -1일 때 Y는 0이 된다. 이 때는 정답이 -3이므로 정답과 약간 벗어났지만, X가 4일 때 추측한 답은 50이고 정답은 7이다.
- 이 정보를 바탕으로 컴퓨터는 다시 추측을 진행하고, 이를 담당하는 것이 **옵티마이저**이다.
- 상황에 따라서 옵티마이저를 적절히 선택
- 손실 함수는 오차(손실)을 계산한 결과가 주어졌을 때 또 다른 추측을 만드는 복잡한 수학 함수
- 이 과정을 반복해 예측의 손실을 최소화, 추측한 식이 정답에 가깝게 만든다.

```python
xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)
```
- 파이썬에서 텐서플로는 넘파이라는 라이브러리 사용하므로 X와 Y를 넘파이 배열로 나열

```python
model.fit(xs, ys, epochs=500)
```
- fit()의 명령으로 훈련 시작
- **X와 Y를 사용해 훈련하고 반복하라**라고 읽을 수 있다.
- 첫 번째 과정부터 반복해나가면서 이 추측이 얼마나 좋고 나쁜지 측정
- 이 결과를 옵티마이저에 피드백해 새로운 추측을 생성
- 손실(오차)가 지남에 따라 줄어드는 로직을 사용해 과정을 반복
- 결과적으로 이 추측은 점점 더 좋아짐

```python
print(model.predict([10.0]))
```
- 훈련된 모델을 사용해 예측을 진행
- 모델은 19에 가까운 답을 출력함

- 모델에 대한 결과는 다음과 같이 생각할 수 있음
1. 손실이 0이 아니라 매우 작은 값이라서 예측이 매우 작은 양만큼만 벗어날 것이라고 예상
2. 이 신경망은 매우 작은 양의 데이터에서 훈련
3. 모델은 하나의 뉴런만 가지고 있다.
4. 뉴런은 가중치와 절편을 학습한다. 따라서 y = wx + b와 같이 나타냄

# 1.5 신경망이 학습한 것 확인

선형 관계에 있는 X와 Y를 매핑하는 예제, 하나의 뉴런이 Y = 2X - 1같은 관계를 가짐
여기서 가중치는 2, 절편은 -1

```python
import tensorflow as tf
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense
```

```python
dense = Dense(units=1, input_shape=[1])
model = Sequential([dense])
model.compile(optimizer='sgd', loss='mean_squared_error')

xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)

model.fit(xs, ys, epochs=500)
print(model.predict([10.0]))
print("신경망이 학습한 것: {}".format(dense.get_weights()))
```
