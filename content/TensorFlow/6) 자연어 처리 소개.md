- 자연어 처리(NLP)는 사람의 언어를 이해하기 위한 인공지능 기술
- 언어를 이해, 말의 내용을 분류, 사람의 언어로 작품을 창작하는 모델
- 챗봇, 생성형 AI 언어 모델 등 이용 가능

# 6.1 언어를 숫자로 인코딩

- 일반적으로 언어는 문자로 인코딩하며 프로그램에서 문자열 저장 시 이런 방식 사용
- 메모리에는 문자 A가 아니라 그 문자에 해당하는 인코딩이 저장
- 표준적으로 많이 사용하는 것이 ASCII OR UTF-8
- 세상에는 인코딩 숫자가 같은 단어들이 어마무시하게 많은 경우 발생
- 이 때문에 텍스트를 이해하는 모델을 구축하기 어려움 
- 자연어 처리는 단어 안의 문자를 인코딩 하는게 아니라 **단어 전체를 숫자로 인코딩**하는 것이다.
- 'I love my dog'와 같은 단어는 숫자[1, 2, 3, 4]로 인코딩
- 'I love my cat'와 같은 단어는 숫자[1, 2, 3, 5]로 인코딩
- 두 문장의 숫자 표현은 비슷하다는 것을 알 수 있고, 이 과정을 **토큰화(tokenization)**라고 함

## 6.1.1 토큰화 시작하기

텐서플로는 preprocessing 패키지에 Tokenizer 클래스라는 단어를 토큰으로 변환하는 API 제공

```python
# 단어를 토큰화
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras.preprocessing.text import Tokenizer

sentences = [
    'Today is a sunny day',
    'Today is a rainy day'
]

tokenizer = Tokenizer(num_words = 100)
tokenizer.fit_on_texts(sentences)
word_index = tokenizer.word_index
print(word_index)
```

```text
{'today': 1, 'is': 2, 'a': 3, 'day': 4, 'sunny': 5, 'rainy': 6}
```

- Tokenizer 객체 생성 시 토큰화할 수 있는 단어 개수 지정
- 이 값은 말뭉치(corpus)에서 추출할 수 있는 최대 토큰 개수
- 토큰화 객체를 만들고 나면 fit_on_texts를 호출해 토큰화된 단어 인덱스를 만든다.
- 이 객체의 word_index 속성을 출력하면 말뭉치 안에 있는 단어와 인덱스의 키/값 쌍이 출력
- 예를 들면 today?와 today~를 모두 today로 필터링
- 이런 동작은 Tokenizer 클래스의 filter 매개변수로 조정
- 이 매개변수의 기본값은 작은 따옴표를 제외한 모든 구두점 제거
- 문장 안에 있는 단어를 인코딩하면 그 다음에는 문장을 숫자의 리스트로 변환
- 이 숫자는 word_index 속성에서 해당 단어를 키로 갖음

## 6.1.2 문장을 시퀸스로 바꾸기

- 첫 번째 과정은 문장 -> 토큰화 -> 숫자
- 그 다음 과정은 문장 -> 숫자의 시퀸스 인코딩
- Tokenizer 클래스는 texts_to_sequences 메서드 제공

```python
# 문자 -> 숫자의 시퀸스 인코딩 변환
sentences = [
    'Today is a sunny day',
    'Today is a rainy day'
]

tokenizer = Tokenizer(num_words=100)
tokenizer.fit_on_texts(sentences)
word_index = tokenizer.word_index
print(word_index)

sequences = tokenizer.texts_to_sequences(sentences)
print(sequences)
```

```text
{'today': 1, 'is': 2, 'a': 3, 'day': 4, 'sunny': 5, 'rainy': 6}
[[1, 2, 3, 5, 4], [1, 2, 3, 6, 4]]
```

일련의 데이터에서 신경망을 훈련하는 과정을 생각해봐라.
- 일반적으로 필요한 데이터 충족 못하지만 많은 양을 커버하는 데이터가 존재
- 자연어 처리의 경우 훈련 데이터에 여러 문맥에서 사용하는 수천 개의 단어가 포함되어 있지만 모든 문맥에서 사용 가능한 모든 단어가 포함되어 있지는 않는다.
- 신경망이 이전에 본 적 없는 단어가 포함된 새로운 텍스트를 만나게 되면 어떤 일이 일어남?
- 새로운 단어의 문맥을 모르기 때문에 결과적으로 예측에 부정적

### OOV 토큰 사용

- 위의 상황을 타계하기 위한 방법은 OOV(Out-of-Vocabulary) 토큰
- 이 토큰은 신경망이 이전에 본 적 없는 단어가 포함된 텍스트의 문맥을 이해하는데 도움
- 다음 문장을 처리할 때

```python
test_data = [
    'Today is a snowy day',
    'Will it be rainy tomorrow?'
]
```

- 이 입력을 훈련 데이터인 기존 말뭉치에 추가하는 것이 아니라 사전에 훈련된 신경망이 이 텍스트를 만났다고 가정해봐라
- 기존에 훈련한 Tokenizer 객체로 이 데이터를 토큰화 진행할 것

```python
test_data = [
    'Today is a snowy day',
    'Will it be rainy tomorrow?'
]

test_sequences = tokenizer.texts_to_sequences(test_data)
print(word_index)
print(test_sequences) # 대부분의 문맥과 의미를 잃어버림, 인코딩 숫자가 무엇인지 잘 모름
```

```text
{'today': 1, 'is': 2, 'a': 3, 'day': 4, 'sunny': 5, 'rainy': 6}
[[1, 2, 3, 4], [6]] 
```

OOV 토큰 사용 시

```python
tokenizer = Tokenizer(num_words = 100, oov_token="<OOV>")
tokenizer.fit_on_sequences(sentences)
word_index = tokenizer.word_index

test_sequences = tokenizer.texts_to_sequences(test_data)
print(word_index)
print(test_sequences)
```

```text
{'<OOV>': 1, 'today': 2, 'is': 3, 'a': 4, 'day': 5, 'sunny': 6, 'rainy': 7} 
[[2, 3, 4, 1, 5], [1, 1, 1, 7, 1]]
```

- fit_on_texts(): 문장을 분석하여 단어 사전을 생성, 입력 데이터는 문자열 문장
- fit_on_sequences(): 정수 시퀸스의 등장 정보 갱신, 입력 데이터는 정수 인덱스 시퀸스
- OOV 토큰은 Tokenizer 클래스의 oov_token 매개변수를 사용

1) 토큰 리스트에 새로운 항목인 "OOV" 추가, 시퀸스 길이도 원본 텍스트 길이 그대로 유지
2) 출력 결과를 복원하면 'today is a oov day'와 'oov it oov rainy oov'

### TextVectorization 층

- 최신 텐서플로에선 텍스트 처리 위한 새로운 TextVectorization 클래스 제공
- 토큰 개수(num_tokens)를 100개로 지정해 클래스 인스턴스 만들어보기
- 기존 코드에서 TextVectorization 사용하기

```python

import tensorflow as tf
from tensorflow.keras.layers import TextVectorization

# 1. 학습 문장
sentences = [
    'Today is a sunny day',
    'Today is a rainy day'
]

# 2. 테스트 문장
test_data = [
    'Today is a snowy day',
    'Will it be rainy tomorrow?'
]

# 3. TextVectorization 생성
# max_tokens=100: 최대 어휘 크기 (특수 토큰 포함)
# output_mode='int': 단어를 정수 인덱스로 변환
# ragged=True: 문장 길이에 맞춰 시퀀스 생성 (패딩 없음)
vectorizer = TextVectorization(
    max_tokens=100,
    output_mode='int',
    ragged=True
)

# 4. 학습 문장으로 단어 사전 생성
# Tokenizer의 fit_on_texts()와 유사한 역할
vectorizer.adapt(sentences)

# 5. 단어 사전 확인
# 인덱스 0: 패딩
# 인덱스 1: OOV ([UNK])
vocab = vectorizer.get_vocabulary()
word_index = {
    word: idx
    for idx, word in enumerate(vocab)
    if word
}

print("단어 사전:", word_index)

# 6. 학습 문장을 정수 시퀀스로 변환
# Tokenizer의 texts_to_sequences()와 유사한 역할
sequences = vectorizer(tf.constant(sentences))
print("학습 시퀀스:", sequences.to_list())

# 7. 테스트 문장을 정수 시퀀스로 변환
# 학습에 없는 단어는 OOV 인덱스 1로 변환
test_sequences = vectorizer(tf.constant(test_data))

print("단어 사전:", word_index)
print("테스트 시퀀스:", test_sequences.to_list())

```

```text
단어 사전: {'[UNK]': 1, 'today': 2, 'is': 3, 'day': 4, 'a': 5, 'sunny': 6, 'rainy': 7} 
학습 시퀀스: [[2, 3, 5, 6, 4], [2, 3, 5, 7, 4]] 

단어 사전: {'[UNK]': 1, 'today': 2, 'is': 3, 'day': 4, 'a': 5, 'sunny': 6, 'rainy': 7} 
테스트 시퀀스: [[2, 3, 5, 1, 4], [1, 1, 1, 7, 1]]
```

### 패딩(padding)

- 신경망 훈련 시 일반적으론 모든 데이터는 크기가 동일 해야 함
- 이미지로 신경망 훈련 시 이미지는 동일한 너비와 높이로 바꿨음
- 텍스트에서도 동일한 이슈가 발생, 단어를 토큰화하고 문장을 토큰의 시퀸스로 바꾸면 시퀸스마타 길이가 다름
- 이때 동일한 길이로 맞추기 위해 패딩(padding)을 사용

```python
# 문장 생성 코드
sentences = [
    'Today is a sunny day',
    'Today is a rainy day',
    'Is it sunny today?',
    'I really enjoyed walked in the snow today'
]

tokenizer.fit_on_texts(sentences)
sequences = tokenizer.texts_to_sequences(sentences)
print(sequences)
```

```text
[[2, 3, 4, 6, 5], 
[2, 3, 4, 7, 5], 
[3, 8, 6, 2], 
[9, 10, 11, 12, 13, 14, 15, 2]]
```

동일한 길이로 만드려면 pad_sequences 함수를 사용할 수 있다.

```python
from tensorflow.keras.preprocessing.sequence import pad_sequences

padded = pad_sequences(sequences)
print(padded)
```

```text
[[ 0  0  0  2  3  4  6  5]
 [ 0  0  0  2  3  4  7  5]
 [ 0  0  0  0  3  8  6  2]
 [ 9 10 11 12 13 14 15  2]]
```

- 보기 좋게 한 줄씩, 시퀸스 길이도 맞춰진 상태로 결과가 출력
- 시퀸스는 단어 리스트에 없는 토큰인 0으로 패딩
- 짧은 문장을 긴 문장의 길이에 맞추기 위해 시작 부분을 0으로 패딩
- 이를 프리패딩(prepadding)이라고 부르며, 이 함수의 기본값
- padding 매개변수에서 이 값을 바꿀 수 있음.

```python
# 프리패딩 적용
padded = pad_sequences(sequences, padding='post')
print(padded)
```

```text
[[ 2  3  4  6  5  0  0  0]
 [ 2  3  4  7  5  0  0  0]
 [ 3  8  6  2  0  0  0  0]
 [ 9 10 11 12 13 14 15  2]]
```

- 패딩된 시퀸스 앞에 단어가 나오고 0이 끝에 추가
- 기본적으로 모든 문장은 가장 긴 문장의 길이에 맞춰 패딩
- 이렇게 하면 잃는 데이터가 없으므로 매우 합리적
- 그 대신에 패딩이 많아짐
- 아주 긴 문장 하나에 맞추기 위해서 패딩이 너무 많이 추가되는 것을 원하지 않는다면?
- 이런 경우는 pad_seqences를 호출할 때 maxlen 매개변수에 최대 길이 지정

```python
# 패딩 길이 설정
padded = pad_sequences(sequences, padding='post', maxlen=6)
print(padded)
```

```text
[[ 2  3  4  6  5  0]
 [ 2  3  4  7  5  0]
 [ 3  8  6  2  0  0]
 [11 12 13 14 15  2]]
```

- 패딩된 시퀸스 길이가 모두 동일하고 패딩이 너무 많이 추가되지 않음
- 그러나 가장 긴 문장의 단어 일부 손실, 문장의 시작 부분도 잘렸음
- 시작 부분이 아니라 문장 끝 부분의 단어를 자르려면 truncating 매개변수를 사용해 바꿀 수 있음

```python
# 문장 끝 부분 잘림
padded = pad_sequences(sequences, padding='post', maxlen=6, truncating='post')
print(padded)
```

```text
[[ 2  3  4  6  5  0]
 [ 2  3  4  7  5  0]
 [ 3  8  6  2  0  0]
 [ 9 10 11 12 13 14]]
```

# 6.2 불용어 제거와 텍스트 정제

- 실전 데이터셋은 원치 않는 텍스트가 들어 있는 경우가 대부분임
- the, and, but과 같이 너무 자주 등장해 특별한 의미가 없는 불용어(stopword)를 제거
- 텍스트에 들어 있는 html 테그를 제거하고 싶은 경우도 있다.
- 무례한 단어, 고유명사, 구두점 등도 제거하고 싶은 경우도 있다.

불용어를 제거하는 방법은 불용어 리스트를 준비하고 문장에서 이를 제거, 전처리하는 방식

```python
# 불용어 리스트 생성
stopwords = [
    # 관사 (Articles)
    'a', 'an', 'the',

    # 인칭대명사 (Personal Pronouns)
    'i', 'me', 'my', 'mine', 'myself',
    'we', 'us', 'our', 'ours', 'ourselves',
    'you', 'your', 'yours', 'yourself', 'yourselves',
    'he', 'him', 'his', 'himself',
    'she', 'her', 'hers', 'herself',
    'it', 'its', 'itself',
    'they', 'them', 'their', 'theirs', 'themselves',

    # 지시대명사 및 의문사
    'this', 'that', 'these', 'those',
    'who', 'whom', 'whose', 'which', 'what',
    'where', 'when', 'why', 'how',

    # 전치사 (Prepositions)
    'in', 'on', 'at', 'by', 'for', 'from',
    'to', 'of', 'with', 'about', 'above',
    'below', 'under', 'over', 'between',
    'through', 'during', 'before', 'after',
    'into', 'onto', 'upon', 'against',
    'among', 'around', 'without', 'within',

    # 접속사 (Conjunctions)
    'and', 'or', 'but', 'so', 'because',
    'although', 'though', 'if', 'while',
    'until', 'unless', 'since', 'as',

    # 조동사 및 일반 동사
    'am', 'is', 'are', 'was', 'were',
    'be', 'been', 'being',
    'have', 'has', 'had', 'having',
    'do', 'does', 'did', 'doing',
    'can', 'could', 'will', 'would',
    'shall', 'should', 'may', 'might', 'must',

    # 부사 및 기타 빈출 단어
    'again', 'also', 'always', 'already',
    'both', 'each', 'every', 'few', 'more',
    'most', 'much', 'many', 'other', 'some',
    'such', 'only', 'own', 'same',
    'than', 'then', 'there', 'here',
    'too', 'very', 'just', 'once',
    'all', 'any', 'another', 'either',
    'neither', 'ever', 'sometimes',
    'often', 'usually', 'really'
]

sentences = [
    'Today is a sunny day',
    'Today is a rainy day'
]

# 불용어 제거 결과를 저장할 리스트
filtered_sentences = []

# 문장을 하나씩 순회하면서 불용어 제거
for sentence in sentences:

    # 문장을 공백 기준으로 단어 분리
    words = sentence.split()

    # 불용어를 제거한 문장을 저장할 변수
    filtered_sentence = ""

    for word in words:

        # 소문자로 변환 후 불용어 여부 확인
        # 불용어가 아닌 단어만 추가
        if word.lower() not in stopwords:
            filtered_sentence = filtered_sentence + word + " "

    # 불용어 제거 결과를 새로운 리스트에 추가
    filtered_sentences.append(filtered_sentence.strip())

# 결과 출력
print(filtered_sentences)
```

```
['Today sunny day', 'Today rainy day', 'beautiful morning']
```

- 또 다른 작업은 불용어 삭제를 방해하는 구두점 제거 
- 앞의 코드는 공백으로 둘러쌓인 불용어만 찾기 때문에 마침표나 쉼표 앞에 오는 불용어를 찾지 못함
- 파이썬 string 패키지에서 제공하는 translate 함수를 사용하면 이런 문제를 해결 가능
- 또한 string.punctuation으로 일반적인 구두점 목록을 제공

```python
# 앞의 불용어 리스트는 동일
# 구두점 목록 확인
# string.punctuation: 일반적인 ASCII 구두점 제공

sentences = [
    'Today is a sunny day.',
    'Today is a rainy day!',
    'This is a beautiful morning, and I am happy.'
]

print("구두점 목록:", string.punctuation)

# 구두점 제거를 위한 변환 테이블 생성
# str.maketrans(변환 전, 변환 후, 삭제할 문자)
# 세 번째 인자에 구두점을 전달하면 해당 문자를 삭제
table = str.maketrans('', '', string.punctuation)

# 전처리 결과 저장 리스트
filtered_sentences = []

# 문장별 구두점 및 불용어 제거
for sentence in sentences:

    # 구두점 제거
    sentence = sentence.translate(table)

    # 공백을 기준으로 단어 분리
    words = sentence.split()

    # 불용어를 제거한 단어 저장
    filtered_words = []

    for word in words:

        # 소문자로 변환한 후 불용어 여부 확인
        if word.lower() not in stopwords:
            filtered_words.append(word)

    # 남은 단어를 공백으로 연결
    filtered_sentence = ' '.join(filtered_words)

    # 전처리 결과 저장
    filtered_sentences.append(filtered_sentence)

# 결과 출력
print("전처리 결과:", filtered_sentences)
```

## 6.3.1 텐서플로 데이터셋에서 텍스트 가져오기

- IMDb 데이터셋에서 훈련 분할, 이를 순회하면서 imdb_sentences 리스트에 리뷰가 담긴 텍스트 필드를 추가

- 레이블은 리뷰의 감성(sentiment) 정보를 나타냄
- tfds.load 함수를 tfds.as_numpy 함수로 감싸서 데이터를 텐서가 아닌 문자열로 로드

