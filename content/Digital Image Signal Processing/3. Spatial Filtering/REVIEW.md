# 3. 공간 필터링 — 검토 내역

검토일: 2026-10-25

## 개념·설명 검토

핵심 설명에서 수정이 필요한 오류를 발견하지 않았다.

filter2D는 상관 연산이다. 합성곱과의 차이, 부호를 보존하는 미분 계산, 양방향 필터의 비선형성, 침식·팽창·열림·닫힘의 순서, DoG의 부드러운 대역 통과 특성을 확인했다. 형태학 수식은 중심 대칭·평탄 구조 요소라는 전제를 유지했다.

## 이번 확인 범위

- 공식 문서와 핵심 개념·수식·함수 설명을 대조했다.
- 설명 수정은 MD와 노트북에 동일하게 반영했다. 계산 코드와 기존 출력은 변경하지 않았다.
- 11개 코드 셀의 Python 구문, MD·IPYNB·practice.py의 계산 코드 일치, 한국어 주석과 표 중앙 정렬을 확인했다.
- 본문의 이미지 경로와 ZIP 내부 파일의 무결성을 확인했다.
- 이번 개념 검토에서 OpenCV 전체 실습을 재실행하지 않았다. 기존 실행 결과와 각 본문에 적힌 검증 범위를 유지했다. 실제 Jupyter Run All을 새로 검증했다는 뜻은 아니다.
