# Tsukuba 실습 변경 및 검토 내역

- 합성 무늬 입력을 첨부된 tsukuba_l.png와 tsukuba_r.png로 바꿨다.
- 임의의 초점거리·베이스라인으로 미터 깊이를 계산하던 실험을 실제 시차와 상대 지표로 교체했다.
- 보정값 미제공, 수평 정렬 및 상대 지표의 주점 차이 0 가정을 본문에 명시했다.
- 좌우 일관성 검사를 추가하고 무효 위치를 NaN으로 유지했다.
- 정답 시차가 없어 MAE와 RMSE를 제거했다. 통과 비율은 정확도로 표시하지 않는다.
- 시차 부호, 16배 고정소수점 변환, SGBM 범위·홀수 블록 조건, 깊이 식의 주점 차이를 검토했다.
- 한국어 코드 주석과 모든 Markdown 표의 중앙 정렬을 유지했다.
- 본문의 실제 실행 결과와 검증 범위는 09_Stereo_Vision.md의 마지막 부분에 기록했다.
