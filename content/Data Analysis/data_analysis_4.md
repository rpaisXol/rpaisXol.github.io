| ------------- | ---------- |
| query()       | 행 추출       |

| groupby()     | 집단별로 나누기   |

| merge()       | 데이터 합치기(열) |

### 문자 변수를 이용해 조건에 맞는 행 추출하기

```python
df = pd.DataFrame({'sex'     : ['F', 'M', 'F', 'M'],

df
```

```python
# 전체 조건에 작은따옴표, 추출할 문자에 큰따옴표 사용
```

### 외부 변수를 이용해 추출하기

- 데이터 프레임에 들어 있는 변수가 아니라 별도의 변수를 이용해 행을 추출하려면 변수명 앞에 @를 붙여서 조건을 입력

```python
var = 3
```

### 데이터 프레임 출력 제한 설정하기

- 노트북은 데이터 프레임이 60행을 넘기면 위아래 5행씩 10행만 출력하고 중간 생략
- 열은 20열을 넘기면 좌우 10열씩 20열만 출력하고 중간을 생략

```python
pd.set_option('display.max_rows', None)     # 모든 행 출력하도록 설정
pd.set_option('display.max_columns', None)  # 모든 열 출력하도록 설정
```

```python
pd.reset_option('display.max_rows')     # 행 출력 제한 되돌리기
pd.reset_option('display.max_columns')  # 열 출력 제한 되돌리기
```

### pandas 함수 조합하기

- pandas의 함수들은 조합하여 함께 사용할 수 있는 장점 활용
- 함수 조합하면 코드 길이가 줄어들고 이해하기 쉬움
- 함수의 출력 결과를 변수에 할당하고 불러오는 작업을 반복하지 않음

#### `query()`와 `[]` 조합하기

- 1반 핛생의 영어 점수를 추출
- nclass가 1인 행을 추출하는 query('nclass == 1')
- english 변수를 추출하는 `['english']`를 연결

```python
# nclass가 1인 행만 추출한 다음 english 추출
exam.query('nclass == 1')['english']
```


```python
# math가 50 이상인 행만 추출한 다음 id, math 추출
exam.query('math >= 50')[['id', 'math']]
```
