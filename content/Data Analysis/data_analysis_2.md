데이터 프레임

- 데이터를 다룰 때 가장 많이 사용되는 데이터 형태
- 행과 열로 구성된 사각형 모양의 표

![[data_analysis_1-1794103940875.webp]]

---

#### **열은 속성이다**

- 새로로 나열되는 열은 속성이며 열은 컬럼 또는 변수라고도 부른다.

#### **행은 하나의 정보이다**

- 가로로 나열되는 행은 정보이며 행은 ROW, 케이스라고 불린다.

#### **하나의 정보는 가로 한 줄에 나열된다**

만약 어떤 데이터에서 한 사람의 100가지 속성에 대한 정보가 담겨 있다면 그 데이터는 100개의 열, 1개의 행으로 표현, 속성이 수만 개더라도 하나의 행으로 표현

#### **하나의 단위가 하나의 행이 된다.**

- 행은 반드시 사람이어야 하는 것은 아니다. 
- 무엇이든 하나의 단위가 행으로 구성될 수 있다.
- 예를들면 하나의 도시 하나의 거래 내역, 하나의 웹 사이트 접속 기록도 하나의 행이 될 수 있음

#### **데이터가 크다. == 행이 많다. 또는 열이 많다.**

- 데이터가 큰건 행 또는 열이 많다는 것을 의미
- 데이터 분석 시 데이터는 열이 많은 것보단 행이 많은 것보다 더 좋다. (열 > 행)

행이 늘어나는 경우
- 예를 들면 데이터가 1만명에서 10만명의 늘어난 데이터를 분석한다고 하면 데이터 분석가는 컴퓨터가 느려지는 현상이 발생
- DRAM, CPU, 클라우드 서비스 이용,  
- 그러나 행이 늘어나더라도 분석 기술에선 별다른 차이가 느껴지지 않음

열이 늘어나는 경우
- 변수를 조합할 수 있는 경우의 수가 하나 더 늘어남
- 변수가 늘어나면 단순 분석 방법 만으로 해결하기 힘드므로 여러 변수의 영향을 동시에 고려하는 복잡한 분석 방법 필요
- 변수가 늘어나면 적용할 분석 기술이 달라지기 때문이다.
- 따라서 데이터 분석에서는 데이터의 양을 의미하는 행보단 데이터의 다양성을 의미하는 열이 많은 것이 더 중요함


#### **1. 데이터 프레임 만들기 - 시험 성적 데이터**

- 데이터 프레임은 데이터를 직접 입력해서 만들거나, 외부 데이터를 가져와서 사용 가능함
- 데이터 프레임을 만들 때는 pandas의 DataFrame()을 이용
- DataFrame()에서 D와 F는 대문자로 입력


```python

df
```
