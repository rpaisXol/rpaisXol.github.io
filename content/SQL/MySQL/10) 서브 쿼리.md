- 서브쿼리(Subquery)는 **하나의 SQL문 안에 포함된 또 다른 SELECT문**이다.
- 메인 쿼리의 조건이나 데이터로 사용된다.
- 사용되는 위치에 따라 스칼라 서브쿼리, 인라인 뷰, 서브 쿼리 3가지로 나눈다.

```
SELECT ...(SELECT ...)
FROM ...

SELECT ...
FROM ...(SELECT ...)

SELECT ...
FROM ...
WHERE 컬럼 = (SELECT ...)
```
# 본질식별자와 인조식별자

# 1. 스칼라 서브쿼리(Scalar Subquery)

- **1행 1열**의 값만 반환
- 주로 SELECT절이나 WHERE절에서 사용
- SELECT AVG(rental_rate) FROM film 에서 AVG()함수는 집계함수이다.

**예제 1. 영화의 평균 대여료와 함께 출력**

```
SELECT title,
       rental_rate,
       (SELECT AVG(rental_rate) FROM film) AS avg_rate
FROM film;
```

# 2. **인라인 뷰 (Inline View)**

- **FROM절에 사용하는 서브쿼리**
- **실행 결과를** **임시 테이블(View)****처럼 사용**

**예제 2. 영화 등급별 평균 대여료 조회**

```
SELECT *
FROM (
    SELECT title, rental_rate
    FROM film
) AS f
WHERE rental_rate >= 4.99;
```

# **3. 서브쿼리 (WHERE절 서브쿼리)**

- **WHERE절에서 조건값으로 사용**
- **단일행 또는 다중행 결과를 반환할 수 있다.**

**예제 3. 평균 film length보다 긴 영화 조회**

```
SELECT title, length
FROM film
WHERE length > (
    SELECT AVG(length)
    FROM film
);

-- where절 서브쿼리 결과가 1열 다수의 행인 경우(벡터 연산자가 필요)
select *
from film
where rating not in
	(select rating from film
	where title= 'ADAPTATION HOLES' 
	or title= 'ACE GOLDFINGER'); -- G, NC17
	
-- where절 서브쿼리 결과 다수의 열인 경우 -> 열을 합쳐서 하나의 스칼라 값으로 연산
select *
from film
where (rating, rental_rate) =
	(select rating, rental_rate from film
	where title= 'ACE GOLDFINGER'); 

-- **where절 서브쿼리 결과 다수의 열 + 다수의 행인 경우 -> 열이 합쳐진 하나의 스칼라 값이 여러행 있으니 벡터연산(1열 여러행가 동일한 연산)
select *
from film
where (rating, rental_rate) in
	(select rating, rental_rate from film
	where title= 'ACE GOLDFINGER'
    or title = 'ADAPTATION HOLES');
