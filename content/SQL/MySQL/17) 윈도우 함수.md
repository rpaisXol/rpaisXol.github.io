# **1. 윈도우 함수(분석함수)**

윈도우 함수(Window Function)는 **from절의 결과셋을 유지하면서** 새로운 계산셋 그룹을 만들어 **집계나 순위 계산을 수행 후 from절의 결과셋에 추가**하는 함수이다.

집계 함수와 가장 큰 차이는 다음과 같다.
- 집계 함수(GROUP BY)**: 여러 행을 하나의 결과로 묶는다.
- 윈도우 함수: 여러 행을 참고해서 계산하지만, 원래의 행은 그대로 유지한다.
- 집계함수는 그룹화된(GROUP BY) 연산 결과를 조회는 목적이고,
- 원도우함수는 그룹화된(PARTITION BY) 연산결과를 원본셋(FROM..WHERE)과 결합(JOIN, 집합,..)하여 조회하는게 목적

원도우 함수가 나오기 전에는 아래 두 결과를 같이 조회하기 위해서는 다음과 같이 조인을 사용하였다.

```sql
SELECT rating,
       AVG(length) AS avg_length
FROM film
GROUP BY rating;
```

![[17 윈도우 함수-1793753563161.webp]]

```sql
SELECT title, length, rating
FROM film;
```
![[17 윈도우 함수-1793753606802.webp]]

```sql
SELECT f.title, f.rating, f.length, t.avg_length
FROM film f INNER JOIN (SELECT rating,
					AVG(length) AS avg_length
					FROM film
					GROUP BY rating) t
ON f.rating = t.rating
ORDER BY f.rating;
```

![[17 윈도우 함수-1793753633679.webp]]

**8.0부터 추가된 윈도우 함수를 사용하면 조인 없이 가능(내부적으로는 조인 발생)**

```sql
SELECT title,
       rating,
       length,
       AVG(length) OVER(PARTITION BY rating) AS avg_length
FROM film;
```

![[17 윈도우 함수-1793753665437.webp]]

GROUP BY는 집계 결과만 출력 가능하지만, 윈도우 함수는 원본 + 집계 결과 함께 출력 가능.

기존 SQL만으로는 다음과 같은 작업이 복잡했다.
1.  순위(RANK) 구하기
2. 이전 행, 다음 행과 비교하기
3. 누적합 계산하기
4. 이동평균 계산하기
5. 그룹별 순위 구하기

- 윈도우 함수를 사용하면 이러한 작업을 GROUP BY 없이 간단하게 처리할 수 있다.
- SELECT절에 서브쿼리가 오면 서브쿼리의 결과와 메인쿼리의 결과를 조인하여 조회된다.

```sql
select name, (select 10 as val) from category;
-- 이 쿼리는 다음과 내부적으로 같이 실행된다
select name, t.val 
from category cross join (select 10 as val) t;
```

```sql
-- 윈도우함수도 비슷하다. 원도우 함수의 결과셋과 메인쿼리 간에 조인이 발생한다.
AVG(length) OVER(PARTITION BY rating) AS avg_length  함수 결과셋과
SELECT title,rating,length FROM film 이 쿼리의 결과셋간에 조인이 발생
```

# 2. 윈도우 함수 문법

```sql
함수() OVER(PARTITION BY 옵션, ORDER BY 옵션, ROWS/RANGE 옵션)
```

**1) OVER()**
- 모든 윈도우 함수는 OVER()가 필요하다.

**2) PARTITION BY**
- GROUP BY와 가장 비슷한 역할을 하지만, 원본 결과 셋은 따로 유지한 채 집계를 위한 별도의 계산 셋 그룹을 생성한다.

**3) ORDER BY**
- 집계함수를 수행 전에 정렬을 진행한다.
- 예) id 순으로 정렬 후 누적합, 성적 순으로 정렬 후 랭킹, ...

**4) ROWS/RANGE**
- ORDER BY옵션이 있다면 추가로 파티션을 다시 쪼개어 윈도우를 지정할 수 있다.(윈도우 슬라이딩 알고리즘을 생각하면 이해가 편할듯)

# **3. 윈도우 함수 종류**

![[17 윈도우 함수-1793753981799.webp]]

**1) ROW_NUMBER()**
- 각 행에 1, 2, 3, ... 순번을 부여한다.
- 같은 값이 있어도 번호가 겹치지 않는다.

```sql
SELECT
    title,
    ROW_NUMBER() OVER(ORDER BY length DESC)
FROM film;
```

- **PARTITION BY 생략되면 전체가 하나의 파티션**
```sql
SELECT
    title, rating,
    ROW_NUMBER() OVER(PARTITION BY rating ORDER BY length DESC) r
FROM film
ORDER BY r;
```

**2) RANK()**
- 순위를 계산한다.
- 같은 값이면 같은 순위를 부여한다.
- 다음 순위는 건너뛴다.

예) 1, 2, 2, 4
```sql
SELECT
    title,
    length,
    RANK() OVER(ORDER BY length DESC)
FROM film;
```

**3) DENSE_RANK()**
- 순위를 계산한다.
- 같은 값이면 같은 순위를 부여한다.
- 다음 순위를 건너뛰지 않는다.

예) 1, 2, 2, 3
```sql
SELECT
    title,
    length,
    DENSE_RANK() OVER(ORDER BY length DESC)
FROM film;
```

**4) NTILE() 그룹 나누기**
- 데이터를 n개의 그룹으로 나눈다.
- 상위 25% : NTLE(4)
- 상위 10% :NTILE(10)
- 4분위수 : NTILE(4)
- 분위 분석 등에 사용된다.

```sql
SELECT
    title,
    length,
    NTILE(4) OVER(ORDER BY length)
FROM film;
```

**5) LAG() 이전 행**
- 현재 행을 기준으로 이전 행의 값을 참조한다.
- 현재 행보다 이전 행의 값을 가져온다.
- 주로 전일 데이터 비교, 이전 매출 비교, 증감 계산 등에 사용된다.

```sql
SELECT
    title,
    length,
    LAG(title) OVER(ORDER BY length)
FROM film;
```

```sql
select *
from (SELECT
	film_id,
	title,
	length,
	LAG(title) OVER(ORDER BY length)
	FROM film) t
where t.film_id = 469;
```

**6) LEAD() 다음 행**
- 현재 행을 기준으로 다음 행의 값을 참조한다.
- 현재 행보다 다음 행의 값을 가져온다.
- 주로 다음 일정, 다음 거래일, 다음 값 비교 등에 사용된다.

```sql
SELECT
    title,
    length,
    LEAD(length) OVER(ORDER BY film_id)
FROM film;
```

**7) CUME_DIST() 누적 분포**
- 데이터가 전체에서 어느 정도 위치에 있는지 계산한다.
- 현재 행 이하의 데이터가 전체에서 차지하는 누적 비율을 반환한다.
- 결과는 0~1 사이의 값이다.

```sql
SELECT
    title,
    length,
    CUME_DIST() OVER(ORDER BY length)
FROM film;
```

상영시간이 짧은 영화부터 정렬한 뒤, 현재 영화의 상영시간 이하인 영화가 전체 영화에서 몇 %를 차지하는지 계산한다.

**8) PERCENT_RANK() 백분위 순위**
- 현재 행의 백분위 순위를 반환한다.
- 가장 작은 값은 0, 가장 큰 값은 1에 가까운 값을 가진다.

```sql
SELECT
    title,
    length,
    PERCENT_RANK() OVER(ORDER BY length)
FROM film;
```

**9) 집계 윈도우 함수**
- 행은 그대로 유지하면서 집계 결과를 함께 표시한다.
- **AVG() OVER()**
- **SUM() OVER()**
- **COUNT() OVER()**
- **MIN() OVER()**
- **MAX() OVER()**

```sql
SELECT
	title, 
    rating,
	COUNT(length) OVER(PARTITION BY rating), 
	SUM(length) OVER(PARTITION BY rating), 
	AVG(length) OVER(PARTITION BY rating), 
	MIN(length) OVER(PARTITION BY rating), 
	MAX(length) OVER(PARTITION BY rating)
FROM film;
```
